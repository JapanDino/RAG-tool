# Проверка работающего приложения и готовности пилота

Дата: 19 сентября 2026 года. Ветка: `JD/canvas-lti-handoff`. Проверка включает ручное прохождение приложения в браузере, а не только чтение кода. Документация: [техническая](TECHNICAL_GUIDE.md), [для пользователей](USER_GUIDE.md), [для администратора Canvas](CANVAS_ADMIN_HANDOFF.md).

## Среда и границы проверки

Запущены production-сборка Next.js на loopback-порту 3100, настоящий FastAPI на 8000, PostgreSQL 16 с pgvector и Redis 7 в отдельных тестовых контейнерах. Использована реальная локальная `multilingual-e5-small` на CPU и реальная Letovo `deepseek-v4-flash`. Учебный текст о фотосинтезе создан специально для проверки; реальных данных учеников нет.

Две браузерные вкладки получили роли преподавателя и ученика через подписанный тестовый LTI-запуск. `/lti/login` и `/lti/launch` выполнялись настоящим приложением; ключ платформы и страницы отсутствующего школьного Canvas предоставляла локальная тестовая оболочка. Она находится только в игнорируемом каталоге и не входит в поставку. Это **не проверка реального браузерного OIDC-перехода через школьный Canvas**, его cookie, Developer Key или сетевых прав REST API.

Автоматические UI-тесты используют подменённый API. Их результаты ниже отделены от ручных действий с работающим сервером.

## Что проверено руками через интерфейс

| Сценарий | Наблюдавшийся результат |
|---|---|
| Вход преподавателя и ученика | Верное название курса и роль; у ученика только чат и материалы |
| Пустой курс | Понятные пустые состояния, нули по шести уровням Блума и четырём метрикам |
| Загрузка MD, DOCX и PDF | Файлы появляются черновиками; извлечённый текст читается в диалоге. PDF проверен с текстовым слоем |
| Иллюстрации PDF/DOCX | Через браузер загружены два документа со схемой фотосинтеза: извлечено по одной картинке. В просмотре показаны подпись DOCX и номер страницы PDF |
| Чат с изображением | Реальный DeepSeek ответил о связи фаз фотосинтеза и приложил схему из опубликованного DOCX; доступна кнопка перехода к материалу |
| Публикация | Опубликованная литература доступна ученику, черновики не отображаются |
| Импорт страниц | Из двух тестовых страниц импортирована одна опубликованная, неопубликованная пропущена; копия остаётся черновиком |
| Анализ Блума | Для учебного фрагмента показаны уровни и пример; есть предупреждение об эвристике и включении черновиков |
| Настоящий чат | На вопрос о связи световой фазы и цикла Кальвина получен ответ с цитатой из литературы |
| Уточняющий вопрос | На «А где происходит каждая из этих фаз?» получен ответ о тилакоидах и строме с источником |
| Вопрос вне темы | На вопрос об автомобильном двигателе показан отказ из-за недостатка информации |
| Отзыв ученика | Оценка «Сложно» и тестовый комментарий сохранены; преподаватель видит категорию и «менее 5», без имени и текста комментария |
| Скрытие материала | Старый пункт списка уже не открывается; после обновления библиотека ученика пуста |
| Метрики | В контрольной точке: 4 вопроса, 2 ответа с источниками, 1 отказ и 1 ошибка; счётчики соответствовали действиям |
| Мобильный интерфейс | Библиотека и отзыв проверены при 390 px, пустая библиотека — при 320 px; горизонтального переполнения не обнаружено |
| Desktop | Просмотрены библиотека, чат с раскрытой цитатой, анализ и сводка; пересечений текста и кнопок не обнаружено |

Часть живых запросов к модели завершилась ошибкой; были также успешные ответы и повторные отправки. Поле сохраняло вопрос для повтора, а в финальной сборке ошибка была видна рядом с ним. После обновления формата E5 и загрузки нового DOCX вновь получен корректный ответ с цитатой: цикл Кальвина происходит в строме хлоропласта. Отдельный короткий запрос к DeepSeek также прошёл, а контрольный запрос к Gemma завершился тайм-аутом. **Проверенная конфигурация чата — DeepSeek; стабильная доступность Letovo и надёжность Gemma не подтверждены.** Один успешный диалог не является оценкой качества RAG на полном курсе.

Автоматическое скачивание весов затянулось; для проверки использована полная локальная копия из официального репозитория Hugging Face. `/health` подтвердил `semantic=true`. Первый запуск и загрузку модели необходимо подготовить на школьном сервере. Физический iPhone и Safari не проверялись.

## Исправления по результатам проверки

- Ошибка чата отображается у поля ввода, а не за пределами видимой области в шапке. Неудавшийся вопрос восстанавливается без дублирования истории.
- Длинный ответ больше не ломает следующий запрос: история ограничивается серверным лимитом на сообщение.
- Сообщения о недоступном материале, лимите запросов и недоступности сервиса переведены на русский.
- Уточнены ограничения файлов/PDF, добавлена предварительная проверка размера; нулевые показатели видны.
- Исправлено поведение длинных названий и кнопок материалов на узких экранах.
- Пустой ответ модели с формально допустимыми цитатами больше не считается успешным. Ошибки поиска учитываются в метриках.
- Для E5 добавлены рекомендованные префиксы документов и запросов. Версия векторов изменена; при обновлении нужна повторная индексация по техническому руководству.
- Главная страница отдельной LTI-сборки ведёт в портал. Контекст Docker исключает локальные виртуальные окружения, сборки Next.js и браузерные отчёты.

Предыдущие проверки зависимостей API/frontend не выявили известных уязвимостей. После установки тяжёлого ML-окружения полный аудит транзитивных ML-зависимостей не повторялся; это не утверждение об отсутствии уязвимостей во всём образе. Backend-образ крупный (около 10 ГБ): CPU-исполнение не исключает CUDA-пакеты из зависимостей PyTorch.

## Что осталось для интеграции

1. Зарегистрировать реальный LTI Developer Key, установить приложение и войти двумя школьными учётными записями.
2. Проверить HTTPS/reverse proxy, cookies, исходящие соединения к Canvas/Letovo и права отдельного Canvas REST-токена на целевом сервере.
3. Проверить реальный курс: полноту импорта, допустимость публикации для всех учеников, минимум 10 контрольных вопросов, цитаты и порог сходства.
4. Измерить нагрузку, холодный запуск и индексацию. Настроить резервные копии, сроки хранения и восстановление.
5. Активировать CI: шаблон `deploy/github-actions-pilot.yml` подготовлен, но раньше GitHub отклонил установку workflow из-за отсутствующего разрешения у OAuth-токена.

Статус: **подготовлено для технической приёмки ограниченного пилота**. Массовая эксплуатация и полная совместимость со школьной установкой Canvas пока не подтверждены. Логичные следующие функции и отличия от исходных пожеланий перечислены в технической документации.
