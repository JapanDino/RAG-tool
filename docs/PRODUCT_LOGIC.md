## Для чего нужен продукт

Помощник помогает ученику разобраться в конкретном курсе и проверить понимание, а преподавателю — подготовить источники и замечать проблемы в материалах и ответах. Canvas задаёт курс и роль пользователя. Источник знаний — опубликованные материалы этого курса и добавленная литература. Преподаватель сохраняет ответственность за публикацию и педагогическую интерпретацию результатов.

Успешный результат для ученика: понятное объяснение, доступный первоисточник, возможность задать уточнение или выполнить упражнение. Успешный результат для преподавателя: проверенная библиотека, понятный статус импорта, обратная связь и журнал добровольно переданных диалогов.

## Путь преподавателя

1. Открыть инструмент из курса Canvas; проверить название и роль.
2. Импортировать страницы и файлы курса или загрузить дополнительную литературу.
3. Прочитать отчёт: что добавлено, что пропущено, где ошибка. Новый материал остаётся черновиком.
4. Проверить извлечённый текст, рисунки и оригинал; опубликовать разрешённое всем ученикам курса.
5. При необходимости включить предложение делиться диалогами и разрешить раскрытие решений после нужного числа попыток.
6. Проверить ответы по нескольким типовым вопросам. Посмотреть курс с ролью ученика.
7. Использовать анализ Блума как предварительную подсказку, сводку отзывов — для поиска сложных материалов, журнал качества — для проверки ответов.
8. После изменения исходных материалов повторить импорт, проверить копии и опубликовать заново.

## Путь ученика

1. Войти из своего курса. Ученик видит чат и опубликованную библиотеку.
2. Задать конкретный вопрос или открыть материал и выбрать фрагмент.
3. Прочитать ответ, раскрыть цитату, перейти к исходному фрагменту или странице PDF. Отличать исходную иллюстрацию от схемы, составленной моделью.
4. Уточнить объяснение кнопками «Объясни проще», «По шагам», «Покажи схему».
5. Запустить «Проверь понимание», ввести собственный ответ, получить проверку и подсказку. Готовое решение доступно по настройке преподавателя. Оценка в Canvas не выставляется.
6. По желанию сохранить локальную историю и заметки. По отдельному согласию делиться вопросами и ответами для контроля качества.
7. Оставить оценку материала. Для развёрнутого сообщения об ошибке обратиться к преподавателю в Canvas.

## Состояния и правила

| Объект | Состояния | Что должен понимать пользователь |
|---|---|---|
| Сессия | Вход / активна / истекла | Отдельного пароля нет; истёкшую сессию открывают заново из Canvas |
| Материал | Импорт / черновик / опубликован / недоступен | Успешная загрузка ещё не означает доступность ученику |
| Импорт | Очередь / обработка / завершён / ошибка | Завершение может включать пропуски и ошибки отдельных элементов; нужен отчёт |
| Ответ | Подготовка / предварительный текст / готов / остановлен / ошибка | Источники проверяют у итогового ответа; остановленный запрос можно повторить |
| Упражнение | Вопрос / попытка / подсказка / решение | Это тренировка с ИИ, а не школьная оценка |
| Журнал качества | Выключен / доступен без согласия / добровольная передача | Настройка преподавателя сама по себе не разрешает запись каждого диалога |
| Локальная история | Не сохранять / сохранять / удалить | Данные остаются в браузере; очистка не отзывает записи, уже переданные в журнал |

Публикация и серверные проверки доступа важнее старого состояния экрана. Изменение настроек журнала обновляется при возврате в чат или окно; обнаруженное отключение сбрасывает согласие. В библиотеке есть обновление без потери основного чата.

## Что обнаружено и исправлено при повторном обходе

- Открытый основной чат показывал старую настройку журнала после её изменения преподавателем. Добавлено обновление при возврате в чат и окно, сброс согласия при отключении и повтор загрузки настроек при сбое.
- Открытая библиотека не предлагала получить новые публикации без перезагрузки всей страницы. Список обновляется при переходе в раздел; добавлена явная кнопка обновления.
- Форма просила необязательный комментарий к материалу, хотя преподавателю выдаются только агрегаты. Неработающее ожидание устранено: форма собирает оценку и объясняет, где сообщить подробности.
- Черновик предлагал разбирать фрагменты при отключённых кнопках. Подсказка теперь предлагает проверку перед публикацией.
- Описание журнала слишком категорично обещало отсутствие имён. Теперь отдельно описаны отсутствие ID и автоматическое маскирование, которое может ошибаться.
- При разрыве соединения проверка упражнения показывала техническое сообщение выше задания. Ошибка переведена на понятный язык и размещена рядом с упражнением; введённый ответ сохраняется.

## Что проверено в работающем сервисе

Локально использовались настоящий frontend, FastAPI, PostgreSQL, Redis, извлечение DOCX/PDF, поиск по материалам и модель Letovo DeepSeek. Вход и Canvas API представлены тестовым курсом; это не проверка школьного Canvas.

| Сценарий | Наблюдение |
|---|---|
| Загрузка DOCX через форму | Появился черновик с текстом и одной извлечённой иллюстрацией |
| Публикация и вход ученика | Дополнительная литература появилась в библиотеке ученика |
| Вопрос по новому DOCX | Получены объяснение по разделам, схема, исходный рисунок и ссылки на DOCX |
| Генерация и проверка упражнения | Создан вопрос о связи световой фазы и цикла Кальвина; модель приняла верный ответ после повтора при разрыве соединения |
| Отзыв ученика | Оценка «Сложно» появилась в преподавательской сводке как «менее 5» |
| Анализ курса | Показаны все три материала; выявлена смысловая ошибка эвристики Блума |
| Истечение сессии | Приложение предложило заново открыть инструмент через Canvas |

Актуальные результаты автоматических и ручных проверок, размеры экранов и ограничения интеграции фиксируются в [отчёте проверки](PILOT_VERIFICATION.md). Проверка нескольких вопросов не доказывает правильность всех будущих ответов модели.

## Граница готовности

Продукт можно передавать администратору для подключения и приёмки пилота. Для утверждения «готов к работе в школе» нужны реальный LTI-запуск по HTTPS, проверка ролей и Canvas-доступов, выбранного LLM endpoint, импорт настоящего курса, нагрузочная проверка, резервное копирование и согласованная политика хранения. Не все данные школьного курса обязаны быть доступны всем ученикам; такие ограничения требуют отдельного сценария приёмки.
