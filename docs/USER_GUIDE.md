# Руководство пользователя: помощник курса

Для учеников и преподавателей. Помощник отвечает по материалам курса, позволяет читать рекомендованную литературу и собирать обратную связь. Преподавателю также доступны предварительный анализ по таксономии Блума и сводные метрики.

Это пилотная версия. Инструкция по подключению для администратора находится в [технической документации](TECHNICAL_GUIDE.md) и [руководстве по установке](CANVAS_ADMIN_HANDOFF.md).

## Как войти

1. Откройте нужный курс в Canvas.
2. Выберите **«Помощник курса»** в меню курса. Он откроется в новой вкладке.
3. Проверьте название курса и роль в верхней части экрана.

Отдельные логин и пароль не нужны. Если ссылка отсутствует, обратитесь к преподавателю или администратору Canvas. Прямой переход по сохранённому адресу без действующей сессии не заменяет вход из курса.

Вход действует один час. Если появилось «Сессия завершилась», откройте помощника заново из Canvas. Разрешите хранилище сайта; при запрете sessionStorage инструмент не сможет сохранить вход.

## Ученику: задать вопрос

1. Откройте **«Чат»**.
2. Выберите предложенный пример вопроса либо введите свой в поле **«Ваш вопрос»**.
3. Нажмите **«Отправить»** и дождитесь ответа. Во время запроса кнопки операций временно недоступны.
4. Под ответом раскройте **«Источник: …»**, прочитайте цитату. Кнопка **«Открыть материал»** показывает извлечённый текст.
5. Если нужно, задайте уточнение: «Объясни проще», «Сравни эти процессы», «Приведи пример из материала».

Хорошие вопросы привязаны к теме: «Чем световая фаза отличается от цикла Кальвина?», «Почему при фотосинтезе выделяется кислород?». Если курс содержит несколько тем, назовите конкретную тему или источник.

Развёрнутые ответы могут содержать заголовки, объяснение по частям и списки. У каждого раздела есть кнопка источника. Для процессов и связей помощник может составить схему с подписанными стрелками. Надпись **«Схема по материалам · составлена помощником»** отличает её от исходной картинки учебника: такую схему тоже нужно сверять с текстом. Если схема не нужна или не подтверждается материалами, ответ остаётся без неё.

Под диалогом доступны кнопки **«Объясни проще»**, **«По шагам»**, **«Покажи схему»**, **«Проверь понимание»**. Они подставляют уточнение по последнему вопросу в поле ввода. Его можно отредактировать, затем нажать **«Отправить»**. Проверка понимания просит помощника задать один вопрос без готового ответа; это упражнение, не оценка в журнале Canvas.

Помимо PDF/DOCX, в ответах могут появляться картинки, прикреплённые к импортированным страницам Canvas. Кнопка **«Открыть источник иллюстрации»** показывает материал; **«Открыть страницу в Canvas»** ведёт на оригинальную страницу курса. Скрытые или изменённые в Canvas картинки могут стать недоступны до повторного импорта преподавателем.

Помощник использует только опубликованные материалы этого курса. Он не ищет ответ во всём интернете. Сообщение «В доступных материалах курса недостаточно информации» означает, что подтверждённого ответа не найдено. Уточните вопрос или спросите преподавателя. Ответы и цитаты всё равно следует проверять: модель может неверно понять текст.

Если модель временно недоступна, вопрос возвращается в поле ввода — его можно отправить снова. При достижении часового лимита попробуйте позже. Максимальная длина вопроса — 4000 символов.

**«Очистить диалог»** удаляет текущую переписку из страницы. После перезагрузки страницы диалог тоже пропадает. Приложение не хранит историю чата в базе и не показывает её преподавателю. Для ответа вопрос, ограниченная история и фрагменты источников передаются настроенному сервису модели. Подробнее — под ссылкой **«Кто видит мой диалог?»**.

## Ученику: читать материал и оставить отзыв

В ответах чата могут появляться иллюстрации из опубликованных PDF/DOCX. Под ними указана страница PDF или абзац DOCX; кнопка **«Открыть источник иллюстрации»** открывает материал. Подбор идёт по подписи и тексту рядом с рисунком. Если подходящей картинки нет, помощник отвечает текстом.

В просмотре материала раздел **«Иллюстрации из материала»** показывает извлечённые картинки. Кнопка **«Скачать оригинал»** доступна для PDF/DOCX, загруженных после обновления. В оригинале можно проверить полный контекст и исходное оформление. После скрытия материала новые запросы картинок и оригинала становятся недоступны ученику.

1. Перейдите в **«Материалы»**.
2. Найдите название через поле **«Поиск по названию»**.
3. Нажмите **«Читать»**. Откроется текст, извлечённый из файла или страницы. Для закрытия используйте кнопку или Escape.
4. Чтобы оценить материал, нажмите **«Оставить отзыв»**.
5. Выберите **«Понятно»**, **«Сложно»** или **«Есть ошибка»**. При необходимости добавьте комментарий и нажмите **«Отправить отзыв»**.

Система показывает преподавателю сводку без имени. В пилоте свободные комментарии сохраняются, но не показываются преподавателю; для срочного сообщения об ошибке свяжитесь с ним обычным способом. Не пишите в комментарии личные данные. Полная техническая анонимность не обещается.

Отзыв относится к материалу, а не к отдельному ответу чата. Не отправляйте его несколько раз ради изменения статистики: число отзывов пока не равно числу разных учеников.

Если библиотека пуста, преподаватель ещё не опубликовал материалы либо источники стали недоступны. Материал, снятый с публикации, нельзя открыть даже по старой цитате; обновите список или обратитесь к преподавателю.

## Преподавателю: подготовить курс

Для материалов с картинками после загрузки проверьте число извлечённых и пропущенных иллюстраций, затем откройте **«Читать»** и убедитесь, что рисунки и подписи правильные. Извлекаются до 20 встроенных растровых картинок. Векторные схемы, внешние картинки, колонтитулы DOCX и сканы без текста пока не поддерживаются. Модель не рассматривает сами пиксели; точность подбора зависит от подписей и окружающего текста. Старые PDF/DOCX нужно загрузить заново, чтобы появились иллюстрации и оригинал.

Перед первым использованием учениками:

1. Войдите из нужного курса и убедитесь, что отображается роль **«Преподаватель»**.
2. Откройте **«Материалы» → «Добавить материалы в курс»**.
3. Загрузите литературу или импортируйте страницы Canvas.
4. Прочитайте извлечённый текст, исправьте исходный документ при необходимости.
5. Опубликуйте только материалы, доступные всем ученикам курса.
6. Проверьте ответы на несколько учебных вопросов и откройте источники.
7. Попросите тестового ученика войти под своей обычной учётной записью. Он должен видеть только опубликованные материалы.

### Загрузить рекомендованную литературу

В блоке **«Добавить литературу»** выберите файл. Поддерживаются TXT, MD, DOCX и PDF с текстовым слоем. Лимиты: 10 МБ, 60 000 извлечённых символов, для PDF — 40 страниц. Большую книгу разделите на главы.

Загрузка и индексация могут занять время. Дождитесь сообщения **«Материал добавлен в черновики»**. Не загружайте повторно тот же файл, пока операция не завершилась.

Сканы PDF без распознанного текста не подходят. Иллюстрации, формулы, таблицы и сложная вёрстка могут извлекаться неточно: обязательно проверьте текст через **«Читать»**. Портал показывает текстовую копию, а не исходный PDF-просмотрщик.

Название файла используется как название материала. Чтобы изменить его, переименуйте исходный файл и загрузите заново; редактора названий и замены версии пока нет. Загрузка ссылки на книгу не поддерживается — нужен файл с разрешённым содержимым.

### Импортировать страницы Canvas

Нажмите **«Импортировать страницы Canvas»**. Нужен настроенный администратором серверный токен Canvas API.

Пилот обрабатывает первые 30 страниц за запуск и пропускает неопубликованные или недоступные страницы. После операции появятся числа импортированных, пропущенных и оставшихся за лимитом страниц, а также извлечённых и пропущенных картинок. Прикреплённые к страницам растровые изображения курса импортируются (до 20 на страницу); внешние картинки и самостоятельные вложения PDF/DOCX, задания, тесты и обсуждения — нет. Повторное нажатие не импортирует «следующие 30».

**Повторный импорт снимает публикацию прежних копий Canvas.** Это происходит до обновления; при ошибке связи они тоже остаются скрыты. Прочитайте и опубликуйте нужные копии заново. Исходные страницы в Canvas не меняются.

Если Canvas изменил, удалил или скрыл страницу, её старая копия перестаёт выдаваться ученику при проверке доступности. Чтобы вернуть её, исправьте источник, повторите импорт и публикацию.

### Управлять доступом

- **«Черновик»** — материал виден преподавателю, но не ученику и не поиску чата.
- **«Опубликовать для всех»** — открывает готовый материал всем участникам пилотного курса.
- **«Скрыть»** — прекращает доступ ученика и использование в новых ответах чата.
- **«Удалить»** — после подтверждения удаляет копию из помощника и связанные отзывы. Корзины нет. Страница в Canvas и файл на вашем компьютере сохраняются.

Фильтр **«Публикация»** показывает все материалы, опубликованные или черновики. Поиск фильтрует список по названию.

Портал не воспроизводит индивидуальные сроки открытия, группы, prerequisites и другие специальные условия Canvas. Не публикуйте материалы, которые разрешены только части класса, ответы к закрытым заданиям или персональные данные.

## Преподавателю: анализ курса

Откройте **«Анализ курса»**. На экране — число фрагментов для уровней «Запомнить», «Понять», «Применить», «Проанализировать», «Оценить», «Создать». Ниже доступны примеры для ручной проверки.

Анализ включает и опубликованные материалы, и черновики. Один фрагмент может относиться к нескольким уровням, поэтому сумма показателей может превышать число фрагментов. В пилоте анализируются первые 500 фрагментов и показываются до 30 примеров.

Классификация основана на словах и глаголах. Используйте её как повод проверить баланс заданий; она не доказывает, что ученик освоил тему. Редактирование классификации прямо в портале пока недоступно.

## Преподавателю: вопросы и обратная связь

В разделе **«Обратная связь»** показаны:

- **Вопросы** — принятые запросы к чату, включая запросы преподавателя.
- **Ответы с источниками** — ответы, прошедшие проверку ссылок на фрагменты.
- **Недостаточно источников** — отказы из-за отсутствия подходящего контекста или допустимых цитат.
- **Ошибки сервиса** — сбои обработки вопроса.

Показатели относятся ко всему периоду накопления и не измеряют успеваемость. Нельзя увидеть имя ученика, личный диалог или индивидуальную активность. Числа отзывов менее пяти скрыты; вместо них показано **«менее 5»**. При отсутствии отзывов отображается пустое состояние.

## Если что-то не работает

| Что видно | Что делать |
|---|---|
| «Войдите через Canvas» | Откройте помощника через меню курса, а не закладку |
| «Сессия завершилась» | Повторите вход из Canvas |
| Запрещено хранилище | Разрешите хранилище сайта; используйте новую вкладку |
| Нет материалов | Преподавателю — загрузить и опубликовать; ученику — уточнить у преподавателя |
| В файле не найден текст | Используйте текстовый документ или PDF с текстовым слоем |
| Превышен лимит | Разделите файл на главы меньшего размера |
| Canvas API недоступен | Администратору — проверить токен и связь; после восстановления повторить импорт и публикацию |
| Модель или поиск недоступны | Подождите и повторите вопрос; если ошибка сохраняется, сообщите администратору |
| Нет подтверждённого ответа | Уточните тему, проверьте публикацию нужного источника |
| Старая цитата не открывается | Источник мог измениться или быть скрыт; обновите материалы |

При обращении за помощью укажите название курса, действие, время и текст ошибки. Не отправляйте API-ключи, токены и содержимое личного диалога без необходимости.

## Работа с клавиатурой и небольшим экраном

Tab перемещает фокус, Enter активирует кнопку. В начале страницы есть ссылка перехода к содержимому. В окне чтения и форме отзыва Tab и Shift+Tab остаются внутри окна; Escape закрывает его, когда не выполняется отправка. После закрытия фокус возвращается к открывшей кнопке.

На телефоне разделы находятся сверху, формы и действия располагаются вертикально. Длинный диалог и текст источника прокручиваются. Для отправки вопроса используется кнопка «Отправить»; Enter в поле добавляет новую строку.

## Чего продукт пока не делает

Нет оценок и баллов в Canvas, автоматических тестов, индивидуального профиля ученика, сохранённой истории чата, автоматической синхронизации всего курса, импорта книги по ссылке и полной анонимности. Возможные следующие функции перечислены в [технической документации](TECHNICAL_GUIDE.md#логичные-следующие-функции).
